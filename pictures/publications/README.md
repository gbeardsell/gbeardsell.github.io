# Publication images

Put one image in each publication entry's folder below, including the PhD thesis.
Supported formats are PNG, JPG, JPEG,
WebP, AVIF, and GIF. Use any filename. If a folder contains multiple supported
images, the first filename alphabetically is used.

You can also add an `alt.txt` file in the same folder with a meaningful description
of the image for people using a screen reader. Without `alt.txt`, the site uses a
generic description based on the publication title.

The development server updates when you save an image or `alt.txt`. Production
needs a rebuild before the change appears. Empty folders leave the publication entry
text-only. Keep `.gitkeep` files so Git retains the empty folders.

The three existing images directly in `pictures/` have no confirmed publication mapping.
They remain untouched and are not assigned to publication entries.
